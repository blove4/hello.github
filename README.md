# Hello, GitHub

A tiny first project for learning how a GitHub repository works.

## Open it

Open `index.html` in a browser. No installation or build step is needed.

## Make your first change

1. Edit the message in `index.html`.
2. Refresh the browser to see the change.
3. Save your work with Git:

```bash
git add .
git commit -m "Create my first GitHub page"
git push
```

The page is intentionally small, so you can experiment with the HTML and CSS without getting lost.
